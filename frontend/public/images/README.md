# Landing assets

Created with the built-in image-generation tool for X-Tracer. Final project assets:

- `connections.webp`: primary connection sculpture.
- `connections-mobile.webp`: responsive smaller version of the same image.
- `evidence.webp`: evidence/document material study.

Optimized WebP files retain the generated compositions; original PNGs remain in the tool's generation output directory.

## Final prompts

### Connections

Use case: stylized-concept. Asset type: premium intelligence software landing page hero, landscape 1536x1024. Create an extraordinary monochrome sculptural visualization of hidden connections: hundreds of delicate silver optical fibers and fine metallic strands curve through space, converging into a single luminous white nexus at right center, like a forensic network rendered as a physical light sculpture. Several small glass-bead connection points, subtly illuminated. Right-heavy composition, deep near-black (#0a0a0a) background, left third almost entirely empty black negative space. Crisp macro photographic realism, exquisite fine detail, slight long exposure trails, controlled white studio rim lighting, museum installation quality, restrained graphite and silver only, no neon colors, no purple, no text, no letters, no UI, no logos, no watermark, no science fiction spaceship. Organic but engineered web of silver threads, beautifully dimensional, cinematic yet minimal. This is an editorial abstract image of relationships becoming visible, not a diagram.

### Evidence

Use case: product-mockup. Asset type: wide editorial image for an intelligence software website, 1536x1024. A beautiful architectural arrangement of thin translucent smoked-glass document sheets, layered like evidence pages, one sheet lifting slightly and casting a precise silver shadow. Fine etched ruled lines on the sheets but no readable text. Shot in a deep graphite studio, monochromatic black and silver, delicate white edge lighting, subtly frosted material, museum-grade contemporary product photography. The glass pages arranged diagonally from bottom left to upper right, filling most frame. Highly tactile and premium, macro detail, quiet and sophisticated. No labels, no text, no hands, no logos, no colored glow, no UI. A physical metaphor for turning fragmented evidence into clarity. Dark background #0a0a0a.
