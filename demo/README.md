# Full investigation demo dataset

`full_investigation_demo.json` is synthetic data for X-Tracer demonstrations. It does not describe real people, accounts, vehicles, places, or transactions.

It is designed to exercise the backend workflow:

- Upload it through **Data file → relationship JSON**.
- Review the cleaned records and build the graph.
- Inspect communities, influence percentages, alerts, entities, filters, and path tracing.
- Open **AI & Evidence Proof** and generate the backend Isolation Forest briefing.
- Seal the evidence, verify the original, test the changed copy, and download a proof bundle.
- Paste the `source_text` into **Add your own data** to demonstrate natural-language extraction separately.

The dataset intentionally contains repeated contacts, cross-community links, payment loops, vehicle/location links, phone and account identifiers, dated events, source-row references, and relationship attributes. It is a demonstration fixture, not ground truth.
